第 1 课 · 程序结构、变量、初始化与编译运行

把以下代码保存为 main.cpp。预处理指令 #include 引入标准库声明，main 是入口，花括号划定作用域，语句通常以分号结束。std::cout 输出到终端，return 0 表示正常退出。

#include <iostream>
#include <string>

int main() {
    const std::string robot_name{"dual_arm"};
    const int joints_per_arm{6};
    double left_joint_rad{0.25};
    const double right_joint_rad{-0.20};
    const bool left_ready{true};
    const bool right_ready{false};
    left_joint_rad = 0.30;

    std::cout << std::boolalpha << robot_name << '\n'
              << "joints per arm: " << joints_per_arm << '\n'
              << "left: " << left_joint_rad << " rad, ready=" << left_ready << '\n'
              << "right: " << right_joint_rad << " rad, ready=" << right_ready << '\n';
    return 0;

int 表示整数，double 表示浮点数，bool 表示真假，std::string 表示文本。{} 初始化变量，能拒绝许多窄化转换，例如 int n{2.5};。局部基本类型变量应在定义时初始化，例如 double voltage_v{}; 得到零。初始化发生在定义时，赋值更新已有对象。const 固定变量，std::boolalpha 让布尔值显示为文字。

double angle_rad{};       // 初始化为 0.0

5 / 2 做整数除法得到 2，5 / 2.0 得到 2.5。= 用于赋值，== 用于比较。&& 在左侧为假时跳过右侧。std::cin >> angle 的结果可以用来判断本次读取是否成功。

怎么写条件和分支

if (条件) { ... } else if (另一个条件) { ... } else { ... } 按顺序检查条件，只执行第一个满足条件的分支。花括号里的局部变量只能在该块中使用。比较表达式 angle_rad > 1.5 的结果是 bool，可以先存到变量里，也可以直接写在括号内。

const bool ready{true};
const double angle_rad{1.6};

if (!ready) {
    std::cout << "not ready\n";
} else if (!std::isfinite(angle_rad) || angle_rad < -1.5 || angle_rad > 1.5) {
    std::cout << "invalid angle\n";
} else {
    std::cout << "ok\n";
}

把片段放进 main 并包含 <cmath>。当前输出 invalid angle。把 ready 改成 false，第一项满足，输出 not ready。当 ready 为真且角度恰好是 1.5 时输出 ok。这里 ! 取反，|| 表示任一条件满足即为真。

用 std::array<double, 6> 表达固定六关节，用 std::vector<double> 表达运行时决定长度的采样序列。按索引遍历时条件写 i < angles.size()。只需要元素值时，用范围循环 for (double angle : angles)。空容器的循环体不会执行。

怎么定义容器和遍历元素

std::array<元素类型, 元素数> 名字{初始值...}; 需要 <array>，长度写在类型里。std::vector<元素类型> 名字{初始值...}; 需要 <vector>，可用 push_back 追加数据。

const std::array<double, 3> home_rad{0.0, 0.1, -0.1};
std::vector<double> samples_rad{};
samples_rad.push_back(0.25);
samples_rad.push_back(-0.20);

for (std::size_t i = 0; i < home_rad.size(); ++i) {
    std::cout << "joint " << i + 1 << ": " << home_rad[i] << '\n';
}
for (double sample_rad : samples_rad) {
    std::cout << "sample: " << sample_rad << '\n';
}

补充 <cstddef> 和 <iostream> 后放进 main。第一个循环从索引 0 开始，每轮末尾执行 ++i，打印 3 个关节。第二个循环只需要读值，直接遍历 2 个样本。注意 std::vector<int> a{3}; 有一个值为 3 的元素，std::vector<int> b(3); 有三个初值为 0 的元素。

第 4 课 · 函数、结构体与枚举

函数把判断规则从打印逻辑中提取出来。小数值用值传递。较大的状态对象可用 const ArmState& 传入，只读访问且省去拷贝。struct 把相关字段组合，enum class 限制状态取值并给枚举名划定作用域。

#include <array>
#include <cmath>
#include <iostream>

struct ArmState {
    bool ready{};
    std::array<double, 6> joint_rad{};
};

enum class Status { ok, not_ready, invalid_angle };

Status check(const ArmState& arm) {
    if (!arm.ready) {
        return Status::not_ready;
    }
    for (double angle : arm.joint_rad) {
        if (!std::isfinite(angle) || angle < -1.5 || angle > 1.5) {
            return Status::invalid_angle;
        }
    }
    return Status::ok;
}

int main() {
    const ArmState left{true, {0.0, 0.5, -1.5, 1.5, 0.3, 0.0}};
    const ArmState right{true, {0.0, 0.0, 1.6, 0.0, 0.0, 0.0}};
    std::cout << std::boolalpha
              << "left ok: " << (check(left) == Status::ok) << '\n'
              << "right ok: " << (check(right) == Status::ok) << '\n';
}

预期左臂为 true，右臂为 false。练习加入状态到文字的转换，优先报告未就绪，再报告角度异常。用 std::numeric_limits<double>::quiet_NaN()（需包含 <limits>）构造非有限值测试。

怎么定义函数、结构体和枚举

  • 函数形式为 返回类型 函数名(参数类型 参数名) { 函数体 }。例如 double corrected_angle(double measured_rad, double offset_rad) { return measured_rad - offset_rad; }。把函数定义放在 main 前，在 main 中调用 corrected_angle(0.25, 0.05)，返回约 0.20。
  • 声明只提供接口，例如 double corrected_angle(double measured_rad, double offset_rad);。若把定义移到 main 后，先在 main 前写这条声明，使编译器在处理调用时知道参数和返回类型。
  • struct 的定义给出成员的名字、类型和默认值。定义末尾写分号。创建结构体对象后，用点号访问成员。
  • enum class 定义一组命名值，用 类型名::值名 访问。可以比较枚举值，再输出对应文字。
struct GripperState {
    double opening_mm{};
    bool ready{};
};

enum class GripperStatus { waiting, open, closed };

GripperStatus classify(const GripperState& state) {
    if (!state.ready) {
        return GripperStatus::waiting;
    }
    return state.opening_mm <= 1.0 ? GripperStatus::closed : GripperStatus::open;
}

在 main 中写 GripperState left{32.0, true};，按成员顺序初始化宽度和就绪标记。调用 classify(left) 返回 GripperStatus::open。执行 left.opening_mm = 0.8; 再调用，返回 closed。把 left.ready 改为 false 后返回 waiting。const GripperState& 让函数读取调用者的对象，函数体内给 state.opening_mm 赋值会报错。

练习与答案　定义一个函数，把两只夹爪中较大的开口宽度返回给调用方。参数写成两个只读引用即可：double wider_mm(const GripperState& a, const GripperState& b) { return a.opening_mm >= b.opening_mm ? a.opening_mm : b.opening_mm; }。传入宽度分别为 32 mm 和 40 mm 的状态，预期返回 40。

第 2 课 · 判断输入是否完整

#include <cmath>
#include <iostream>

bool in_range(double angle_rad) {
    return std::isfinite(angle_rad) && angle_rad >= -1.5 && angle_rad <= 1.5;
}

int main() {
    double left{}, right{};
    if (!(std::cin >> left >> right)) {
        std::cerr << "expected two angles\n";
        return 1;
    }
    std::cout << std::boolalpha << in_range(left) << ' ' << in_range(right) << '\n';
}

输入 -1.5 1.5 得到 true true，输入 0 1.51 得到 true false，输入 0 motor 报读取失败。即使左边成功写入，右边读取失败后也应停止本次判定。

第 3 课 · 找出异常关节

以下函数接受一只臂的采样序列。把它放在 main 前并包含 <vector>、<string> 和 <cstddef>，沿用上题的 in_range。

std::size_t report(const std::string& side, const std::vector<double>& angles) {
    std::size_t errors{};
    for (std::size_t i = 0; i < angles.size(); ++i) {
        if (!in_range(angles[i])) {
            ++errors;
            std::cout << side << "_joint_" << i + 1 << ": " << angles[i] << '\n';
        }
    }
    return errors;
}

先用 angles.empty() 处理缺失，再调用函数。输入 {0, 0, 0, 0, 0, 1.6} 时返回 1，并打印第六关节。数组索引从 0 开始，关节编号从 1 开始。

第 4–5 课 · 综合检查器参考解

沿用第 4 课的类型与 check，把下列函数加入源文件并替换原有 main。读入格式为每臂一个 0/1 和六个角度，共 14 个字段。以下代码需要额外包含 <cstddef>。

const char* label(Status status) {
    switch (status) {
        case Status::ok: return "ok";
        case Status::not_ready: return "not_ready";
        case Status::invalid_angle: return "invalid_angle";
    }
    return "unknown";
}

bool read_arm(const char* name, ArmState& arm) {
    int ready{};
    if (!(std::cin >> ready) || (ready != 0 && ready != 1)) {
        std::cerr << name << " ready must be 0 or 1\n";
        return false;
    }
    arm.ready = ready == 1;
    for (std::size_t i = 0; i < arm.joint_rad.size(); ++i) {
        if (!(std::cin >> arm.joint_rad[i])) {
            std::cerr << name << " missing or invalid angle at joint " << i + 1 << '\n';
            return false;
        }
    }
    return true;
}

int main() {
    ArmState left{}, right{};
    if (!read_arm("left", left) || !read_arm("right", right)) {
        return 1;
    }
    std::cout << "left: " << label(check(left)) << '\n';
    std::cout << "right: " << label(check(right)) << '\n';
}

0 1.6 0 0 0 0 01 0 0 0 0 0 1.6左臂未就绪，右臂角度异常
1 0 0 0 0 0 01 0 0 后结束输入提示右臂第 3 个角度缺失，退出码 1

第 1 课 · 对象、地址、引用和指针

第 2 课 · 存储期、生命周期与失效

块内普通局部变量通常具有自动存储期，离开块时销毁。局部 static 对象可以跨调用存活。动态分配对象的存活时间由其所有权管理。存储期描述存储的持续时间，生命周期描述对象何时存在。常见实现用栈承载自动变量、用堆承载动态分配，编译器也可以把局部值放在寄存器中。

std::vector 扩容重新分配时，旧元素的指针、引用和迭代器都失效。返回局部变量的地址同样会留下悬空指针。以下缓存返回一个值副本，调用方可在缓存更新后继续读取旧快照。

#include <iostream>
#include <optional>
#include <vector>

struct Sample {
    double left_rad;
    double right_rad;
};

class History {
public:
    void append(Sample sample) { samples_.push_back(sample); }

    std::optional<Sample> latest() const {
        if (samples_.empty()) {
            return std::nullopt;
        }
        return samples_.back();
    }

private:
    std::vector<Sample> samples_;
};

int main() {
    History history;
    std::cout << std::boolalpha << history.latest().has_value() << '\n';
    history.append({0.25, -0.20});
    const auto snapshot = history.latest();
    history.append({0.30, -0.10});
    if (snapshot) {
        std::cout << snapshot->left_rad << '\n';
    }
}

预期输出 false 与 0.25。std::optional 表示零个或一个值，解引用前先检查。练习给缓存增加最多保留 100 帧的规则，验证第 101 帧加入后第一帧被丢弃，旧快照仍可读。

第 3 课 · 数据源接口、缺失与超时

以下示例以单调时钟判断样本新鲜度，避免系统时间调整影响经过时长。接口析构函数为虚函数，使通过基类指针销毁派生对象时执行正确的析构过程。由调用者注入检查时间，测试可精确覆盖边界。

#include <algorithm>
#include <array>
#include <chrono>
#include <cmath>
#include <iostream>
#include <memory>
#include <optional>

using Clock = std::chrono::steady_clock;
using namespace std::chrono_literals;

struct Sample {
    std::array<double, 2> joint_rad;
    Clock::time_point stamp;
};

class Source {
public:
    virtual ~Source() = default;
    virtual std::optional<Sample> read() = 0;
};

class SimSource final : public Source {
public:
    explicit SimSource(Clock::time_point stamp) : stamp_(stamp) {}
    std::optional<Sample> read() override {
        return Sample{{0.25, -0.20}, stamp_};
    }

private:
    Clock::time_point stamp_;
};

enum class State { missing, stale, invalid, ok };

State check(const std::optional<Sample>& sample, Clock::time_point now) {
    if (!sample) {
        return State::missing;
    }
    if (sample->stamp > now || now - sample->stamp > 100ms) {
        return State::stale;
    }
    constexpr double limit = 1.5;
    const auto& angles = sample->joint_rad;
    const bool valid = std::all_of(angles.begin(), angles.end(), [limit](double angle) {
        return std::isfinite(angle) && std::abs(angle) <= limit;
    });
    return valid ? State::ok : State::invalid;
}

int main() {
    const auto start = Clock::now();
    std::unique_ptr<Source> source = std::make_unique<SimSource>(start);
    const auto sample = source->read();
    std::cout << std::boolalpha
              << (check(sample, start + 100ms) == State::ok) << '\n'
              << (check(sample, start + 101ms) == State::stale) << '\n';
}

预期两行均为 true。练习加入空数据源和回放数据源。约定每行两个角度，回放格式错误时报告行号，文件结束时返回缺失。把两个角度扩展为双臂各六个。

第 4 课 · 并发采集与快照

先完成单线程监测器，再让采集线程写入最新帧，监测线程读快照。访问共享缓存时用同一个 std::mutex，读写各自用 std::lock_guard<std::mutex> 自动解锁。持锁期间只拷贝或替换快照，出锁后再判定和打印。用 std::atomic<bool> 传递退出标记，确保线程可退出并在资源销毁前调用 join()。使用 GCC 在 Linux 构建线程示例时加 -pthread。

第 3 课 · 空数据源与回放数据源

class EmptySource final : public Source {
public:
    std::optional<Sample> read() override { return std::nullopt; }
};

class ReplaySource final : public Source {
public:
    explicit ReplaySource(const std::string& path) : input_(path) {
        if (!input_) {
            throw std::runtime_error("cannot open " + path);
        }
    }

    std::optional<Sample> read() override {
        std::string line;
        if (!std::getline(input_, line)) {
            if (input_.bad() || !input_.eof()) {
                throw std::runtime_error("replay read failed");
            }
            return std::nullopt;
        }
        ++line_number_;
        std::istringstream fields{line};
        double left{}, right{};
        std::string extra;
        if (!(fields >> left >> right) || fields >> extra) {
            throw std::runtime_error("invalid row " + std::to_string(line_number_));
        }
        return Sample{{left, right}, Clock::now()};
    }

private:
    std::ifstream input_;
    std::size_t line_number_{};
};

构建 ReplaySource("angles.txt")，在 main 用 try / catch (const std::exception& error) 捕获并输出 error.what()。一行正常数据读完后再次读取，得到 nullopt。若第二行是 0.2 motor，得到 invalid row 2。本例以读取时间作为样本时间，第四阶段再加入录制的相对时间。扩为 12 个关节时，把数组长度改为 12，用范围循环逐项读值，读完后检查多余字段。

第 2 课 · 回放行解析参考解

此实现约定无空白的字段格式，使用点号作为小数点。解析错误返回空值，角度范围由原库单独判断。把下面的解析函数放到库实现文件，公开声明放到对应头文件。

#include <charconv>
#include <cmath>
#include <locale>
#include <optional>
#include <sstream>
#include <string>

struct Row {
    long long time_ms;
    double left_rad;
    double right_rad;
};

bool parse_angle(const std::string& field, double& value) {
    std::istringstream input{field};
    input.imbue(std::locale::classic());
    return (input >> std::noskipws >> value) && input.eof() && std::isfinite(value);
}

std::optional<Row> parse_row(const std::string& line) {
    const auto first = line.find(',');
    if (first == std::string::npos) {
        return std::nullopt;
    }
    const auto second = line.find(',', first + 1);
    if (second == std::string::npos || line.find(',', second + 1) != std::string::npos) {
        return std::nullopt;
    }
    Row row{};
    const char* const time_end = line.data() + first;
    const auto time = std::from_chars(line.data(), time_end, row.time_ms);
    if (time.ec != std::errc{} || time.ptr != time_end || row.time_ms < 0 ||
        !parse_angle(line.substr(first + 1, second - first - 1), row.left_rad) ||
        !parse_angle(line.substr(second + 1), row.right_rad)) {
        return std::nullopt;
    }
    return row;
}

在读取循环维护 std::optional<long long> previous。若 !row，报告当前行格式错误。首行要求 row->time_ms == 0，后续行要求 row->time_ms >= *previous。接受该行后更新 previous，再调用 valid_angle。遇到角度异常可继续处理余下帧，记录是否出现过异常，最终按表格约定返回退出码；输入格式错误立即返回 2。

第 3 课 · 完整订阅节点参考解

将第四阶段的 monitor.hpp 与 monitor.cpp 复制到本包的 include/ 与 src/。以下示例以最后一次收到消息为超时依据，收到坏帧仍记录接收时间，同时单独报告数据错误。默认单线程执行器串行运行订阅与定时器。

保存为 src/joint_monitor.cpp。

#include <chrono>
#include <cstddef>
#include <memory>
#include <optional>
#include <rclcpp/rclcpp.hpp>
#include <sensor_msgs/msg/joint_state.hpp>
#include "monitor.hpp"

using namespace std::chrono_literals;
using JointState = sensor_msgs::msg::JointState;
using Clock = std::chrono::steady_clock;

class JointMonitor final : public rclcpp::Node {
public:
    JointMonitor() : Node("joint_monitor") {
        subscription_ = create_subscription<JointState>(
            "joint_states", rclcpp::QoS(10),
            [this](JointState::ConstSharedPtr msg) { inspect(*msg); });
        timer_ = create_wall_timer(50ms, [this] {
            if (!timed_out_ && Clock::now() - last_rx_ > 500ms) {
                timed_out_ = true;
                RCLCPP_WARN(get_logger(), "joint state reception timeout");
            }
        });
    }

private:
    void inspect(const JointState& msg) {
        last_rx_ = Clock::now();
        timed_out_ = false;
        if (msg.name.size() != msg.position.size()) {
            RCLCPP_WARN(get_logger(), "name and position lengths differ");
            return;
        }

        std::optional<double> left, right;
        for (std::size_t i = 0; i < msg.name.size(); ++i) {
            auto* angle = msg.name[i] == "left_joint_1" ? &left :
                          msg.name[i] == "right_joint_1" ? &right : nullptr;
            if (angle == nullptr) {
                continue;
            }
            if (angle->has_value()) {
                RCLCPP_WARN(get_logger(), "duplicate joint: %s", msg.name[i].c_str());
                return;
            }
            *angle = msg.position[i];
        }
        if (!left || !right) {
            RCLCPP_WARN(get_logger(), "missing expected joint");
            return;
        }
        RCLCPP_INFO(get_logger(), "left=%s right=%s",
            monitor::valid_angle(*left) ? "ok" : "invalid",
            monitor::valid_angle(*right) ? "ok" : "invalid");
    }

    Clock::time_point last_rx_{Clock::now()};
    bool timed_out_{};
    rclcpp::Subscription<JointState>::SharedPtr subscription_;
    rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    rclcpp::spin(std::make_shared<JointMonitor>());
    rclcpp::shutdown();
}
