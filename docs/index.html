例子中的变量和类型沿用本阶段的上下文，语句可放到相应示例中尝试。

  • 程序入口。
    执行程序时进入的函数。
    用法：int main() { return 0; }
  • 头文件。
    让编译器看到库或项目接口的声明。
    用法：#include <iostream> → std::cout << "ready";
  • 变量。
    有名字、类型和生命周期的对象。
    用法：double angle_rad{0.25}; angle_rad = 0.3;
  • 基本类型。
    用整数、浮点数和真假值表达不同数据。
    用法：int joints{6}; double voltage_v{24.2}; bool ready{true};
  • 字符串。
    保存可变长度的文本。
    用法：std::string joint{"left_joint_1"}; // <string>
  • 列表初始化。
    用花括号提供初值，许多窄化转换会被拒绝。
    用法：double angle_rad{}; // 0.0
  • 常量。
    用 const 禁止通过该名字修改对象。
    用法：const double limit_rad{1.5};
  • 条件分支。
    按条件决定执行哪个代码块。
    用法：if (angle_rad > limit_rad) { std::cout << "invalid"; }
  • 逻辑运算。
    用取反、且、或组合判断。
    用法：if (ready && angle_rad <= limit_rad) { /* 记录状态 */ }
  • 输入提取。
    尝试读取值，可检查流是否成功。
    用法：if (!(std::cin >> angle_rad)) { return 1; }
  • 定长数组。
    元素类型和数量都写在类型里。
    用法：std::array<double, 6> joints_rad{}; // <array>
  • 动态数组。
    容器可随采样增删改变长度。
    用法：std::vector<double> samples; samples.push_back(0.25); // <vector>
  • 索引循环。
    需要位置时，用索引访问元素。
    用法：for (std::size_t i = 0; i < joints_rad.size(); ++i) { std::cout << joints_rad[i]; }
  • 范围循环。
    直接依次访问元素。
    用法：for (double rad : joints_rad) { std::cout << rad; }
  • 函数。
    为一段有输入或返回结果的逻辑命名。
    用法：double correct(double rad, double offset) { return rad - offset; }
  • 结构体。
    把一组相关数据组合为一种类型。
    用法：struct Arm { bool ready{}; double rad{}; }; Arm left{true, 0.25};
  • 作用域枚举。
    给有限状态命名，用类型名限定枚举值。
    用法：enum class State { ok, invalid }; State current{State::ok};
  • 作用域。
    名字只能在其声明允许的范围内使用。
    用法：if (ready) { double local_rad{0.25}; } // 块外无法访问 local_rad

示例 1.2.1

5 / 2.0 的结果是 2.5。

概念 1.2.2

怎么写条件和分支

  • if (条件) { ... } else if (另一个条件) { ... } else { ... } 按顺序检查条件，只执行第一个满足条件的分支。
  • 花括号里的局部变量只能在该块中使用。
  • 比较表达式 angle_rad > 1.5 的结果是 bool，可以先存到变量里，也可以直接写在括号内。

示例 1.2.2

// 为什么这样写：先检查就绪，再检查角度，可明确异常优先级。
// 运行结果：本例输出 invalid angle；ready 改为 false 后输出 not ready。

const bool ready{true};
const double angle_rad{1.6};

if (!ready) {
    std::cout << "not ready\n";
} else if (!std::isfinite(angle_rad) || angle_rad < -1.5 || angle_rad > 1.5) {
    std::cout << "invalid angle\n";
} else {
    std::cout << "ok\n";
}

把片段放进 main 并包含 <cmath>。
当前输出 invalid angle。
把 ready 改成 false，第一项满足，输出 not ready。
当 ready 为真且角度恰好是 1.5 时输出 ok。
这里 ! 取反，|| 表示任一条件满足即为真。

解答 1.2.1 · 读取并校验双臂角度

判断输入是否完整

// 为什么这样写：先检查输入流，再检查有限性和闭区间。
// 运行结果：边界值通过，1.51 不通过，文字输入使程序退出 1。

#include <cmath>
#include <iostream>

bool in_range(double angle_rad) {
    return std::isfinite(angle_rad) && angle_rad >= -1.5 && angle_rad <= 1.5;
}

int main() {
    double left{}, right{};
    if (!(std::cin >> left >> right)) {
        std::cerr << "expected two angles\n";
        return 1;
    }
    std::cout << std::boolalpha << in_range(left) << ' ' << in_range(right) << '\n';
}

第 3 课 · 循环和容器

1. 概念与对应示例

本课要点
  • 索引表示元素位置，关节编号比索引大 1。
  • 空容器应报告缺失，不能视为全部通过。

概念 1.3.1

  • 用 std::array<double, 6> 表达固定六关节，用 std::vector<double> 表达运行时决定长度的采样序列。
  • 按索引遍历时条件写 i < angles.size()。
  • 只需要元素值时，用范围循环 for (double angle : angles)。
  • 空容器的循环体不会执行。

怎么定义容器和遍历元素

  • std::array<元素类型, 元素数> 名字{初始值...}; 需要 <array>，长度写在类型里。
  • std::vector<元素类型> 名字{初始值...}; 需要 <vector>，可用 push_back 追加数据。

示例 1.3.1

// 为什么这样写：array 表达固定关节数，vector 便于追加采样；需要关节编号时使用索引。
// 运行结果：先打印三个关节，再打印两个样本；索引条件改成 <= 会访问末尾之外。

samples_rad.push_back(0.25);
samples_rad.push_back(-0.20);

}
for (double sample_rad : samples_rad) {
    std::cout << "sample: " << sample_rad << '\n';
}

补充 <cstddef> 和 <iostream> 后放进 main。

第二个循环只需要读值，直接遍历 2 个样本。
注意 std::vector<int> a{3}; 有一个值为 3 的元素，std::vector<int> b(3); 有三个初值为 0 的元素。

3. 解答

解答 1.3.1 · 定位越界关节

找出异常关节

以下函数接受一只臂的采样序列。
把它放在 main 前并包含 <vector>、<string> 和 <cstddef>，沿用上题的 in_range。

// 为什么这样写：用索引生成关节名，用计数器记录异常项。
// 运行结果：末项为 1.6 时报告第六关节；调用前应单独识别空数据。

std::size_t report(const std::string& side, const std::vector<double>& angles) {
    std::size_t errors{};
    for (std::size_t i = 0; i < angles.size(); ++i) {
        if (!in_range(angles[i])) {
            ++errors;
            std::cout << side << "_joint_" << i + 1 << ": " << angles[i] << '\n';
        }
    }
    return errors;
}

先用 angles.empty() 处理缺失，再调用函数。
输入 {0, 0, 0, 0, 0, 1.6} 时返回 1，并打印第六关节。
数组索引从 0 开始，关节编号从 1 开始。

核对结果
左臂全零、右臂第六个角度为 1.6 时，仅报告 right_joint_6，总数为 1；空数据报告 missing。

#include <cmath>
#include <iostream>

    对象可以随运行时的所有者创建和销毁。

    对象从初始化完成到开始销毁之间可供正常访问。

  • 大小与对齐。
    大小描述占用字节数，对齐描述地址约束。

    声明给出接口，定义提供实现。

第 2 课 · 存储期、生命周期与失效

1. 概念与对应示例

本课要点
  • 缓存拥有容器元素，按值返回的快照有独立生命周期。

概念 2.2.1

  • 块内普通局部变量通常具有自动存储期，离开块时销毁。
  • 局部 static 对象可以跨调用存活。
  • 动态分配对象的存活时间由其所有权管理。
  • 存储期描述存储的持续时间，生命周期描述对象何时存在。
  • 常见实现用栈承载自动变量、用堆承载动态分配，编译器也可以把局部值放在寄存器中。
  • std::vector 扩容重新分配时，旧元素的指针、引用和迭代器都失效。
  • 返回局部变量的地址同样会留下悬空指针。
  • 以下缓存返回一个值副本，调用方可在缓存更新后继续读取旧快照。

示例 2.2.1

// 为什么这样写：optional 表达空缓存，返回值副本独立于内部容器。
// 运行结果：先输出 false，追加第二帧后旧快照仍打印 0.25。

#include <iostream>
#include <optional>
#include <vector>

struct Sample {
    double left_rad;
    double right_rad;
};

class History {
public:
    void append(Sample sample) { samples_.push_back(sample); }

    std::optional<Sample> latest() const {
        if (samples_.empty()) {
            return std::nullopt;
        }
        return samples_.back();
    }

private:
    std::vector<Sample> samples_;
};

int main() {
    History history;
    std::cout << std::boolalpha << history.latest().has_value() << '\n';
    history.append({0.25, -0.20});
    const auto snapshot = history.latest();
    history.append({0.30, -0.10});
    if (snapshot) {
        std::cout << snapshot->left_rad << '\n';
    }
}

示例 3.3.1

// 为什么这样写：注入检查时间使边界可重现，虚析构支持经基类释放对象。
// 运行结果：两行都打印 true，分别验证 100 ms 有效和 101 ms 超时。

#include <algorithm>
#include <array>
#include <chrono>
#include <cmath>
#include <iostream>
#include <memory>
#include <optional>

using Clock = std::chrono::steady_clock;
using namespace std::chrono_literals;

struct Sample {
    std::array<double, 2> joint_rad;
    Clock::time_point stamp;
};

class Source {
public:
    virtual ~Source() = default;
    virtual std::optional<Sample> read() = 0;
};

class SimSource final : public Source {
public:
    explicit SimSource(Clock::time_point stamp) : stamp_(stamp) {}
    std::optional<Sample> read() override {
        return Sample{{0.25, -0.20}, stamp_};
    }

private:
    Clock::time_point stamp_;
};

enum class State { missing, stale, invalid, ok };

State check(const std::optional<Sample>& sample, Clock::time_point now) {
    if (!sample) {
        return State::missing;
    }
    if (sample->stamp > now || now - sample->stamp > 100ms) {
        return State::stale;
    }
    constexpr double limit = 1.5;
    const auto& angles = sample->joint_rad;
    const bool valid = std::all_of(angles.begin(), angles.end(), [limit](double angle) {
        return std::isfinite(angle) && std::abs(angle) <= limit;
    });
    return valid ? State::ok : State::invalid;
}

int main() {
    const auto start = Clock::now();
    std::unique_ptr<Source> source = std::make_unique<SimSource>(start);
    const auto sample = source->read();
    std::cout << std::boolalpha
              << (check(sample, start + 100ms) == State::ok) << '\n'
              << (check(sample, start + 101ms) == State::stale) << '\n';
}

回放行解析参考解

此实现约定无空白的字段格式，使用点号作为小数点。

// 为什么这样写：严格检查分隔符、字段消耗和有限性，避免接受部分数字。
// 运行结果：格式错误返回空值，合法但越界的角度留给业务规则判断。

#include <charconv>
#include <cmath>
#include <locale>
#include <optional>
#include <sstream>
#include <string>

struct Row {
    long long time_ms;
    double left_rad;
    double right_rad;
};

bool parse_angle(const std::string& field, double& value) {
    std::istringstream input{field};
    input.imbue(std::locale::classic());
    return (input >> std::noskipws >> value) && input.eof() && std::isfinite(value);
}

std::optional<Row> parse_row(const std::string& line) {
    const auto first = line.find(',');
    if (first == std::string::npos) {
        return std::nullopt;
    }
    const auto second = line.find(',', first + 1);
    if (second == std::string::npos || line.find(',', second + 1) != std::string::npos) {
        return std::nullopt;
    }
    Row row{};
    const char* const time_end = line.data() + first;
    const auto time = std::from_chars(line.data(), time_end, row.time_ms);
    if (time.ec != std::errc{} || time.ptr != time_end || row.time_ms < 0 ||
        !parse_angle(line.substr(first + 1, second - first - 1), row.left_rad) ||
        !parse_angle(line.substr(second + 1), row.right_rad)) {
        return std::nullopt;
    }
    return row;
}

在读取循环维护 std::optional<long long> previous。
若 !row，报告当前行格式错误。
首行要求 row->time_ms == 0，后续行要求 row->time_ms >= *previous。
接受该行后更新 previous，再调用 valid_angle。
遇到角度异常可继续处理余下帧，记录是否出现过异常，最终按表格约定返回退出码；输入格式错误立即返回 2。

// 为什么这样写：按名称关联位置，用单调时钟监测最后接收时间。
// 运行结果：重排数组仍能正确判定；停发超过阈值后提示超时。

#include <chrono>
#include <cstddef>
#include <memory>
#include <optional>
#include <rclcpp/rclcpp.hpp>
#include <sensor_msgs/msg/joint_state.hpp>
#include "monitor.hpp"

using namespace std::chrono_literals;
using JointState = sensor_msgs::msg::JointState;
using Clock = std::chrono::steady_clock;

class JointMonitor final : public rclcpp::Node {
public:
    JointMonitor() : Node("joint_monitor") {
        subscription_ = create_subscription<JointState>(
            "joint_states", rclcpp::QoS(10),
            [this](JointState::ConstSharedPtr msg) { inspect(*msg); });
        timer_ = create_wall_timer(50ms, [this] {
            if (!timed_out_ && Clock::now() - last_rx_ > 500ms) {
                timed_out_ = true;
                RCLCPP_WARN(get_logger(), "joint state reception timeout");
            }
        });
    }

private:
    void inspect(const JointState& msg) {
        last_rx_ = Clock::now();
        timed_out_ = false;
        if (msg.name.size() != msg.position.size()) {
            RCLCPP_WARN(get_logger(), "name and position lengths differ");
            return;
        }

        std::optional<double> left, right;
        for (std::size_t i = 0; i < msg.name.size(); ++i) {
            auto* angle = msg.name[i] == "left_joint_1" ? &left :
                          msg.name[i] == "right_joint_1" ? &right : nullptr;
            if (angle == nullptr) {
                continue;
            }
            if (angle->has_value()) {
                RCLCPP_WARN(get_logger(), "duplicate joint: %s", msg.name[i].c_str());
                return;
            }
            *angle = msg.position[i];
        }
        if (!left || !right) {
            RCLCPP_WARN(get_logger(), "missing expected joint");
            return;
        }
        RCLCPP_INFO(get_logger(), "left=%s right=%s",
            monitor::valid_angle(*left) ? "ok" : "invalid",
            monitor::valid_angle(*right) ? "ok" : "invalid");
    }

    Clock::time_point last_rx_{Clock::now()};
    bool timed_out_{};
    rclcpp::Subscription<JointState>::SharedPtr subscription_;
    rclcpp::TimerBase::SharedPtr timer_;
};

int main(int argc, char** argv) {
    rclcpp::init(argc, argv);
    rclcpp::spin(std::make_shared<JointMonitor>());
    rclcpp::shutdown();
}

解答 5.4.2 · 建立双臂坐标关系

实现步骤
在 URDF 中定义 base_link、left_link、right_link。
创建两个 continuous 关节，父链接均为 base_link，子链接分别为 left_link 和 right_link，旋转轴设为 0 0 1。
将 URDF 作为 robot_description 参数启动 robot_state_publisher，发布名称匹配的 JointState，再运行 ros2 run tf2_ros tf2_echo base_link right_link 对比两个角度。

<!-- 为什么这样写：两个关节共用基座并绕 Z 轴旋转，名称需与消息一致。 -->
<!-- 运行结果：右关节角度变化后可观察 right_link 相对基座的旋转变化。 -->

<robot name="dual_arm_demo">
  <link name="base_link"/>
  <link name="left_link"/>
  <link name="right_link"/>
  <joint name="left_joint_1" type="continuous">
    <parent link="base_link"/>
    <child link="left_link"/>
    <origin xyz="0 0.3 0"/>
    <axis xyz="0 0 1"/>
  </joint>
  <joint name="right_joint_1" type="continuous">
    <parent link="base_link"/>
    <child link="right_link"/>
    <origin xyz="0 -0.3 0"/>
    <axis xyz="0 0 1"/>
  </joint>
</robot>

核对结果
右关节角度改变时，right_link 相对 base_link 的旋转随之改变。
